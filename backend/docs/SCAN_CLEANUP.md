# 扫盘清理

扫盘按目录存在性判断哪些视频可以退出媒体库。失败目录只保护自身子树；当前配置范围完整时，已确认消失的记录立即清理。

后端路径均相对 `backend/`：`internal/scanner/` 负责发现与对账，`internal/catalog/scan_presence.go` 判断缺失候选，`cmd/server/scan.go` 编排清理。跳过目录保存接口位于 `internal/api/admin_drive_operations.go`，前端为根目录 `src/admin/drive/SkipDirsPanel.tsx`。

## 执行顺序

```mermaid
flowchart LR
    A["任务准入、挂载与配置"] --> B["发现<br/>只读快照"]
    B --> C["对账<br/>更新记录与祖先链"]
    C --> D["跳过目录策略清理"]
    D --> E["缺失文件清理"]
    E --> F["投递派生任务"]
```

策略清理必须在对账后执行：文件从跳过目录移出时，先更新祖先链，再按新位置判断。`SeenFileIDs` 额外保护本轮已发现的文件，即使祖先链更新失败也不按旧链删除。

根目录最终列举失败、正常发现耗尽限流预算或对账发生致命错误时，本轮不进入清理。管理员停止、服务退出等任务取消会终止后续处理。

## 存在性证据

发现快照中的目录集合互不重叠：

| 集合 | 字段 | 含义 |
| --- | --- | --- |
| E | `EnumeratedDirIDs` | `List` 成功的目录 |
| F | `FailedDirIDs` | 最终重试后仍打不开的子目录 |
| X | `ExcludedDirIDs` | 命中跳过配置、未进入的目录 |

`PresenceAuthoritative()` 表示扫描起点已进入 E，且 F 与发现阶段 `Issues` 均为空。完整性针对**当前配置范围**，不要求从物理网盘根开始；X 是主动排除，不算错误。对账写库或策略清理的局部错误不改变已形成的存在性证据。

视频的 `ancestor_dir_ids` 保存从扫描起点到直接父目录的有序 ID 数组，含两端。旧记录没有链时，以非空 `parent_id` 作为单元素链；否则视为空链。目录 ID 是不透明值，不能按 `/` 拆分。

## 缺失清理

`EvaluateMissingDriveFiles` 根据快照和有效祖先链选出候选，再由共用删除函数清理记录与本地资产。

- 本轮已见文件清零历史缺失计数。
- 当前范围存在性完整时，候选立即清理，不新增缺失标记，并清除旧标记。
- 发现不完整时，候选累计两次确认才清理；受保护的记录不删除、不推进计数。

对未见文件，沿有效链从起点查找第一个不在 E 的目录 `di`：

| 条件 | 处理 |
| --- | --- |
| 链中所有目录都在 E | 父目录存在、文件缺失，进入候选集 |
| `di` 在 F | 保护该子树 |
| `di` 在 X | 交给策略清理；缺失清理不计数 |
| `di` 不在 E/F/X，且前一个祖先在 E | 已成功枚举的父目录未列出该子目录，进入候选集 |
| 第一个祖先不在 E/F/X，或链为空 | 仅在当前范围完整且未设置 `ProtectUnlocated` 时进入候选集 |

切换或缩小扫描根后，旧范围记录适用最后一条规则，完整扫描后退出媒体库。若仍有待处理的跳过目录旧数据，设置 `ProtectUnlocated`，仅保护无法映射到 E/F/X 的旧记录，不把整盘降级。

## 跳过目录策略

保存名单只更新配置，不启动扫描或删除。**下次扫描对账后**才按名单清理；在此之前取消跳过可保留记录。取消后重新扫描可入库，但已删除记录的手动标签和播放记录不恢复。

名单变化或仍有旧数据待处理时执行：

1. **按链精确清理**：选择有效链与跳过名单有交集的记录，排除本轮已见文件后删除，不访问网盘。
2. **处理无祖先链的旧记录**：没有此类记录时直接标记完成；否则逐个遍历尚未完成的跳过目录，按枚举成功目录及起点的 `parent_id` 查记录，排除本轮已见文件后删除。嵌套跳过目录分别处理。
3. **记录进度**：完整遍历并删除成功的目录单独标记完成，后续只重试未完成项。精确清理成功后记录当前名单；旧数据处理尚未完成时保留待办状态。

遍历不完整时，已找到的记录仍清理，未完成目录留待下次重试。普通查询、删除和进度写入错误记入 `[skip-cleanup]` 日志与扫描结果，继续缺失清理及派生任务；X 下残留记录仍受保护。

## 重试与取消

| 情况 | 行为 |
| --- | --- |
| 请求超时、连接重置、EOF 等临时传输错误 | 每次读目录原地最多重试两次；等待 1 秒、3 秒，附加最多 25% 随机延迟；仍失败则延后到最终重试轮 |
| 网盘限流 | 冷却 10 分钟后重试同一目录；正常发现和旧数据处理共用本轮最多 3 次冷却重试预算 |
| 鉴权、权限、证书等非临时错误 | 不额外重试，子目录进入 F；根目录失败终止本轮 |
| 任务取消 | 打断请求或等待，在后续写入前终止本轮 |

第 4 次限流时返回预算耗尽：正常发现尚未形成可对账结果，终止本轮；对账后的旧数据处理则结束策略步骤，保留已完成快照，继续缺失清理。

常规遍历结束后，对临时失败目录追加一次最终重试轮，仍使用上述短重试和共享限流预算。恢复成功的目录从 F 移入 E；此轮新发现的失败目录不再加入延后队列，避免无限扩展。根目录最终失败则终止本轮。

临时错误分类和退避由 `internal/readretry/` 共享。后台目录浏览独立使用相同策略，总期限为 45 秒；115 SDK 读取沿用 15 秒预算，不在驱动写操作外叠加重试。

## 持久化与升级

| 位置 | 用途 |
| --- | --- |
| `videos.ancestor_dir_ids` | JSON 祖先链；发现与对账逐步更新旧记录，不在启动时回填 |
| `drives.skip_cleanup_dir_ids` | 精确清理已完成的名单，NULL 表示从未执行 |
| `drive_skip_cleanup_legacy_dirs` | 按 `(drive_id, dir_id)` 保存旧数据处理进度 |
| `drive_scan_misses` | 保护模式的缺失计数，重新见到或删除视频时清除 |

新增列须同时维护迁移、`currentVideoColumnNames`、`Video` / `VideoMetaPatch` 和读写语句，避免表重建丢列。备份按表处理。

## 删除语义与边界

- 两种清理共用删除函数，移除 Catalog 记录、关联、本地封面、预览及帧签名；**不删除网盘源文件，不写墓碑**。爬虫盘、站内上传盘和 Telegram 本地盘不参与。
- 同盘任务共享互斥门；扫描期间修改的跳过配置在当前租约结束后生效。资产与 Catalog 联动删除受 `persistence` 锁保护。
- 文件移入失败子树，但旧父目录连续两次证明其缺失时，旧记录仍可能被删除；恢复扫描后重新入库，原手动标签和播放记录丢失。
- 上游成功响应却静默返回空列表、漏页或截断数据时，系统可能视为完整并立即清理；驱动必须校验分页并显式返回异常。
- WebDAV、本地盘等以路径为 ID 的驱动，目录重命名按旧位置缺失、新位置入库处理。名为 `previews` 的目录正常扫描，只按配置名单排除目录。
